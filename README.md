# Acadeva Desktop Releases

This repository hosts built installers for the Acadeva desktop app (Windows, macOS, and Linux). It contains release artifacts only, no source code.

## Download

Grab the latest installer from the [Releases page](https://github.com/Acadeva/acadeva-desktop-releases/releases/latest):

## Staying up to date

Acadeva checks for updates automatically and installs them in the background, so once you've installed it you shouldn't need to come back here for future versions. To check manually, open the app, go to Settings > About, and select "Check for updates."

## Support

This repository is for distribution only, issues and pull requests opened here aren't monitored. For help or feedback, visit [acadeva.xyz](https://acadeva.xyz) or reach out from within the app.
